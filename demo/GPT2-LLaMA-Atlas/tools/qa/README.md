# 浏览器验证

```bash
npm run qa:session
npm run qa:browser
```

`qa:session` 用假浏览器验证共享锁、软件渲染拦截、超时、异常与信号清理，不启动 Chrome、不绘制 3D。

`qa:browser` 依次运行生成/温度检查和 Llama 课程/来源检查。保留原有 89 + 60 项检查、HTTP/file:// 入口和隔离学习记录。使用本机安装的 Google Chrome、临时独立 profile 和现有 Playwright 环境。

两套脚本共用 `browser-session.mjs`：

- 先取得 `127.0.0.1:4240` 的排他锁，再启动浏览器；单独同时运行两套脚本也会排队。等待上限 120 秒，端口冲突或权限不足会明确报错。内核在进程退出时释放锁，无 PID 锁文件。
- 用 1×1 空画布读取实际 WebGL 渲染器，只接受 `ANGLE Metal Renderer`。缺少 Chrome/WebGL、出现 SwiftShader 或不能确认 Metal 时直接失败，不在 CPU 上回退跑 3D。
- 单套总运行上限 180 秒；启动 15 秒、连接 10 秒；默认页面操作 10 秒、导航 15 秒，显式轨迹加载等待仍按各检查指定的上限。
- 正常完成、断言异常、总超时、SIGINT/SIGTERM/SIGHUP 都进入同一清理路径。优先正常关闭，5 秒超时后只强制结束本次启动的浏览器进程组，关闭所登记的测试 HTTP 服务器，最后释放锁。
- 处理中止的启动请求会等待其完成或启动超时，再关闭迟到的浏览器，避免启动阶段中断造成遗漏。
- SIGKILL 无法运行 JavaScript 清理逻辑；这里只保证共享锁由内核释放，不声称 SIGKILL 后还能执行上述浏览器清理。
- 报告保存实际 renderer、浏览器 PID、开始/结束时间和 `completed`。运行失败即非零退出，不将部分检查记成整套通过。

完整验证会打开 3D 网页；本次没有进行逼近 90°C 的温度压力测试。Metal 后端与串行执行已验证，不据此承诺温度峰值。
